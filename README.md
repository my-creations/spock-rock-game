# Spock Rock Game

A Rock–Paper–Scissors–Lizard–Spock browser game against the computer, built with vanilla JavaScript.

## Features

- All five gestures with win/lose/tie logic
- Player vs computer scoring
- Confetti celebration on wins (`confetti.js`)

## Run it

Just open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```
